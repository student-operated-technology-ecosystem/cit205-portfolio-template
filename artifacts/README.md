# Add your own artifact PDFs here

Complete and save each authentic artifact in Microsoft Word first. After instructor review and removal of sensitive information, use **File → Save As / Export → PDF** to make a browser-readable copy. Keep your editable Word original in your normal course workspace; upload the public-safe PDF to this folder through **Add file → Upload files**, then **Commit changes**.

Use these exact filenames to match the starter website links:

- workstation-validation.pdf
- server-validation.pdf
- phone-support-ticket.pdf
- email-support-ticket.pdf
- knowledge-base-article.pdf
- troubleshooting-decision-tree.pdf
- mission-proposal.pdf
- ticket-and-knowledge-review.pdf
- documentation-vocabulary.pdf
- github-evidence.pdf
- resume.pdf

**Do not submit placeholder files as finished evidence.** The starter website already hides PDF links until your evidence exists. Once you upload a matching PDF, edit `index.html` to remove the `hidden` attribute on that artifact's `<a>` link and commit the update. Leave unfinished links hidden; publishing a PDF alone does not add it to the page.

Redact private information, credentials, internal addresses, and confidential records before publishing.
